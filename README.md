# Elmontag Hub (GitLab)

Elmontag Hub is a simple web application that allows users to view and add repositories, and manage user authentication (sign up and login).

## Features

- **Repository Management**: View a list of repositories and add new ones.
- **User Authentication**: Sign up and log in with user credentials.
- **Dynamic Navigation**: Show or hide navigation options based on user authentication status.


# Repositories Viewer

Welcome to the Repositories Viewer project! This simple web application allows you to display a list of repositories from a JSON file.

## Features

- **Display Repositories**: Fetch and display repositories from a `repos.json` file.
- **Dynamic Content**: Automatically load and list repository details including name, description, and owner.

## Prerequisites

- Basic knowledge of HTML, CSS, and JavaScript.
- A modern web browser that supports JavaScript.
